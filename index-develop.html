01 · 用法

文字意圖至 HTML 的實體映射

輸入意圖字串，機制即將其在 1 個指令中分配至 8 種類型之一並分流至繁中或英文語軌。

「影 · kage」覆蓋 8 種類型邊界：單頁摘要、長篇報告、個股研報、作品集、商務書信、更新日誌、簡報與產品頁。每種類型以 JSON Schema 內容契約做物理約束，將 AI 文案鎖定於字數上限內。

全數 16 份模板凝固為單檔自包含 HTML，共享 45 個色彩 token 與全域 CSS 阻尼。無編譯器或前端框架依賴，產出檔可直接落盤並在瀏覽器中讀取。

05 · 材質

4 層物理堆疊的光影底板

背景由四層實體疊加：繪製基色、暖色漏光、可選的中央沉暗層，顆粒永遠置頂。弧線與塵點歸屬裝飾語彙，不計入層數。

純色像素缺乏物理抗力。機制載入固定種子生成的 200×200 灰階 PNG 顆粒，在繪製層沉澱出標準差 7.4 的無彩雜訊。

漏光能量按 3 類頁面階梯分級：敘事型高階設為 24%/19%，閱讀型抑制至 10%/8%。光源錨點留在畫面外，中央正文欄明度不越過 20 刻度。

L1 · 繪製基色
純黑 #000000。這是實際畫下去的顏色，不是你看到的顏色。
L2 · 暖色漏光
screen 疊加。核心錨定在畫面之外，畫面內只有衰減尾端。
L3 · 中央沉暗（選用）
只在背景是全幅影像時需要。純色底不需要 —— 中央本來就最暗。
L4 · 膠片顆粒
normal 混合，永遠最上層。合成後全圖明度約 12.8。

09 · 問答

關於「影 · kage」的實體機制問答

解析定位、生成範疇、光學來源與顯影模式的 4 個機制疑問。

1. 「影 · kage」是什麼？
「影 · kage」是引導 AI Agent 輸入至 HTML 實體的文件生成 Skill。它錨定 16 份模板與 45 個色彩 token 的物理結構，作為設計系統展示基準。
2. 「影 · kage」能生成什麼？
覆蓋 8 種類型實體：單頁摘要、長篇報告、個股研報、作品集、商務書信、更新日誌、簡報與產品頁，繁中與英文共 16 份純螢幕 HTML 模板。
3. 核心美學精神是什麼？
質感來自底片膠卷與老電影的物理光影。藉由 #000000 基色、7.4 標準差無彩顆粒與 18–30° 邊緣漏光衰減，將像素高頻光點轉譯為銀鹽感光層上的沉澱記錄。
4. 什麼是顯影模式？
顯影模式將抽象宣示降維至客觀物理刻度。該語域屬於罕用狀態，預設為關閉，需使用者在指令中輸入明確指定方可解鎖實體對應轉譯。
