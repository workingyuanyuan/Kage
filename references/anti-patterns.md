# 稿件與版面診斷

審查時按觀察到的問題使用下列判準。內容策略見 [writing.md](writing.md)，排印與元件規格見 [design.md](design.md)，背景與色彩規格見 [material.md](material.md)。

## 內容與來源

| 問題 | 修正 |
|---|---|
| 主張只有形容詞，讀者無法判斷效果 | 補上有來源的數據或可觀察事實；移除無法支持的主張。 |
| 把無來源的「23.7%」改成「約 24%」 | 約數也需要依據。查找支持資料，或標示必要缺口。 |
| 圖表、內文或不同語系的數據不一致 | 核對來源、期間、單位與統計口徑，更新本次交付涉及的版本。 |
| 宣稱「最新」卻沒有時間依據 | 核實所指狀態並標示適用日期；歷史版本依其原始發布紀錄處理。 |
| 無證據的市場地位或平台支援承諾 | 只描述資料支持的定位、功能與已驗證範圍。 |
| 以通用文字填滿模板、湊案例或功能數量 | 保留有實質內容的區塊，依需求調整版面。 |
| 圖說只是重述標題，或推斷了沒有依據的因果 | 補充可支持的觀察、識別資訊或分析，區分推論。 |
| 正文出現製作指示、限制清單或自我評價 | 依 SKILL.md 的輸出規則，改為讀者需要的內容與必要行動。 |

## 圖像與可讀性

| 問題 | 修正 |
|---|---|
| 缺圖時交疊標題壓到圖說 | 使用 `.plate-wrap--gap` 保留與預期圖片相當的高度，見 design.md「3.4 圖片框架」。 |
| 圖庫中的截圖比例不同，重要內容被裁掉 | 以一致外框與內距容納原圖，按內容決定裁切。 |
| 產品畫面經重繪後與真實介面不符 | 使用可核對的截圖；原型或示意圖清楚標明性質。 |
| 小字橘棕色在漏光區難讀 | 改用 `--color-text-on-dark`，用底線或其他結構表達強調；見 material.md「2.4 對比與可存取性」。 |
| 圖表撐出整頁水平捲軸 | 在圖表自身的 `overflow-x: auto` 容器內捲動。 |
| 圖像與短文交替排列形成過大空洞 | 調整對齊、欄寬或合併相關區塊，使閱讀順序連續。 |

## 元件與交付細節

下列情況發生時再採用相應修正，數值可依實際字型與元件驗證。

| 問題 | 修正 |
|---|---|
| 貨幣符號浮在價格上方 | 保持符號與數字共用基線；既有元件可用 `font-size: .74em; line-height: 1; transform: translateY(.015em)`。 |
| 語言選單切斷 g / y / p 下緣，或移入時消失 | 留足行高與內距，檢查觸發區到選單的指標路徑；既有元件可用 `line-height: 1.35` 與透明橋接區。 |
| 數字基線或欄位對齊跳動 | 在相關數字節點使用 `font-variant-numeric: lining-nums tabular-nums`。 |
| 分享圖的實際格式與副檔名或 MIME 不符 | 依目標平台要求正確編碼並核對格式。 |
| 頁面中的星數、價格或下載數已過期 | 使用有日期的快照；需要動態更新時採用適合交付環境的資料流程。 |
| 含正文的截圖造成背景像素檢查失敗 | 以 `shot --bg-only` 產生背景截圖，再用匹配頁型的 `bg --tier` 檢查。 |
| 搬移 HTML 後字型與顆粒消失 | 核對相對路徑與交付資產；見 [production.md](production.md)「文件製作」。 |
